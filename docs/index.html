Biometric Architecture

How FakePaste Simulates Human Biology

Most typing software operates like an electrical oscillator: fixed intervals and zero variance. FakePaste replaces clock loops with a non-linear human neuromuscular latency pipeline.

Stage 01

Gaussian Keystroke Jitter

Keystrokes are computed using a Box-Muller transform:
t_delay = (60 / CPM) · (1 + Z · σ) Every character arrives with a distinct physical strike delay, preventing periodic clock detection.

core/typer.py:L86-L92
Stage 02

QWERTY Adjacency Matrix

When humans mistype, their fingers slip to physically adjacent keys on the keyboard grid. FakePaste maps all 40+ key coordinates: typing 'd' probabilistically slips to s, e, r, f, or c.

ADJACENT_KEYS = {'d': 'serfcx'}
Stage 03

Cognitive Realization Lag

Real humans do not instantly backspace the millisecond an error happens. FakePaste simulates the 180ms–350ms neural feedback loop where the brain registers the typo before triggering hand recovery.

latency: 180ms - 320ms reaction
Stage 04

Backspace Correction Loop

Upon recognizing an error, the engine simulates 1–2 rapid backspaces (using tactile backspace velocity), followed by a brief 100ms hesitation, and re-strikes the correct character.

_do_typo_sequence()
Stage 05

Punctuation & Syntax Breathing

Typists hesitate at structural boundaries. FakePaste injects 150ms–600ms pauses at periods, commas, colons, and questions marks, plus 0.8s–2.0s rests at paragraph breaks.

punctuation_pause_min = 0.15s
Stage 06

Low-Level Kernel Intercept

Powered by native pynput keyboard listener. Hitting the physical ESC key aborts simulation instantly from any window across the entire OS in under 1 millisecond.

utils/hotkeys.py: HotkeyManager

cd FakePaste
pip install -r requirements.txt
python main.py
To build your own standalone EXE: python build.py
